# Contributing to PikaDecks

Welcome to PikaDecks! We appreciate your contributions to help make this AI-powered learning platform even better.

## 🤝 Code of Conduct
By participating in this project, you agree to keep interactions constructive, professional, and respectful.

## 🛠️ How to Contribute

1. **Fork the Repository**: Create a personal clone of the repository.
2. **Create a Feature Branch**: Work on your changes in a branch named after the feature or issue (e.g., `feature/srs-optimization` or `bugfix/expo-navigation`).
3. **Write Clear Commit Messages**: Detail what changed and why.
4. **Follow Linting & Formatting Guidelines**:
   - For python backends, run code formatters.
   - For javascript/typescript frontends, run `npm run format`.
5. **Submit a Pull Request**: Explain your changes and verify that all local checks pass.
